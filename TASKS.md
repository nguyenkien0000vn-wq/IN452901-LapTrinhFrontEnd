## Ghi chú chấm

- Kiểm chứng chung: `npm ci && npm run lint && npm run typecheck && npm test && npm run build && npx playwright install chromium && npx playwright test` xanh (solution: 24/24 Vitest, 3/3 Playwright). Không nộp `node_modules`, `.next`, `test-results`, `playwright-report`, `.env.local`.
- Thứ tự phụ thuộc (đã kiểm bằng cách chép từng phần solution vào starter): Vitest xanh 12 → 16 (T1) → 16 (T2, T3 kiểm bằng e2e) → 21 (T4) → 24 (T5). Playwright cần cả T1–T6.
- Trừ điểm ở nhiệm vụ tương ứng: gọi API từ Client Component thẳng tới cổng 4000 hoặc lưu token vào `localStorage` (T4/T5, tối đa nửa điểm); dùng `middleware.ts`, `getServerSideProps`, Pages Router (T2–T4); `'use client'` cho cả trang công khai (T2, T3 — trang công khai phải là Server Component); đọc `cookies()`/`searchParams` ngoài `<Suspense>` khiến build báo lỗi blocking route (T2).
- Bản deploy dùng mock API công khai của giảng viên (`--public`): Admin mẫu chỉ xem được, nên T6 chấm phần tạo sự kiện bằng e2e/CI hoặc demo trên máy.
- ESLint ở Ch06 là bản 9 (theo `create-next-app`), không phải 10 — plugin của `eslint-config-next` 16.4 chưa hỗ trợ ESLint 10.
